## Описание 
Данная работа посвящена статистическому анализу расстояний между соседними собственными значениями случайных вещественных симметричных матриц. В теории случайных матриц этот феномен известен как **расталкивание уровней**. 

В ходе лабораторной работы моделируется поведение случайных матриц для двух типов распределений их элементов:
1. **Гауссов ортогональный ансамбль (GOE):** Элементы генерируются из нормального распределения $\mathcal{N}(\mu = 0, \sigma = 1)$.
2. **Ансамбль Бернулли:** Элементы принимают значения $\\{-1, 1\\}$ равновероятно.

### Алгоритм исследования

Для каждого ансамбля случайных матриц фиксированного размера $k \times k$ выполняется следующий численный эксперимент:

1. **Генерация ансамбля:** Создается выборка из $N = 10000$ случайных матриц. Случайными независимыми величинами заполняется верхний треугольник матриц (включая диагональ), после чего матрицы симметризуются: $A = A^T$.
2. **Вычисление собственных чисел:** Находятся действительные собственные значения матриц $\lambda_i$ с использованием метода `np.linalg.eigvalsh`.
3. **Нормировка расстояний:** Вычисляется разность между двумя соседними собственными числами $\Delta = \lambda_{2} - \lambda_{1}$. Для корректного сравнения матриц разных размеров и ансамблей с разной дисперсией производится нормировка полученных разностей на их среднее значение:
   $$s = \frac{\Delta}{\langle\Delta\rangle}$$
4. **Сравнение с теорией:** Строится гистограмма плотности распределения нормированных разностей $s$ и сопоставляется с теоретическим **распределением Вигнера** для ортогонального ансамбля:
   $$\rho_\Delta (s) = \frac{\pi s}{2} e^{-\frac{\pi s^2}{4}}$$

### Реализация и результаты

Скрипт проводит симуляции для матриц размерностей $k \in \\{2, 4, 16, 32, 64\\}$. Графики распределений плотности автоматически сохраняются в формате PDF в директорию `imgs/` с именами вида `{dist_type}-{N}-{k}.pdf`. 

Визуализация позволяет проследить, как с ростом размерности матрицы $k$ статистическое распределение разностей собственных чисел (даже дискретного ансамбля Бернулли) сходится к плавному теоретическому распределению Вигнера.

## Результаты

### 1. Поведение гистограммы в окрестности нуля (Расталкивание уровней)
На всех построенных графиках плотность распределения в нуле стремится к нулю ($\rho_\Delta(0) = 0$). Это ключевое свойство случайных матриц, которое называется **эффектом расталкивания уровней**. 

* **Смысл:** Вероятность того, что два собственных числа окажутся очень близко друг к другу (или совпадут, образуя вырожденное состояние), крайне мала. Для того чтобы матрица имела кратные собственные числа, её элементы должны удовлетворять жестким алгебраическим ограничениям. Случайная флуктуация элементов "расталкивает" собственные значения. 
* В отличие от полностью независимых случайных величин (где работала бы статистика Пуассона с максимумом плотности в нуле $\rho(s) = e^{-s}$), спектр случайных матриц демонстрирует сильную корреляцию.

### 2. Сравнение графиков с распределением Вигнера
* **Для Гауссова ансамбля:** Сгенерированная гистограмма показывает очень хорошее совпадение с теоретической кривой Вигнера при любых $k$. Для $k = 2$ распределение Вигнера является строгим аналитическим решением. С ростом размерности матрицы ($k \to \infty$) гистограмма продолжает с высокой точностью следовать этой кривой, подтверждая универсальность распределения расстояний между уровнями для гауссовых ортогональных ансамблей.
* **Для ансамбля Бернулли:** 
  * При малых размерах матриц ($k = 2, k = 4$) наблюдается ярко выраженная **дискретность**. Поскольку элементы матрицы могут принимать строго фиксированные значения $\pm 1$, спектр и разности собственных чисел также принимают ограниченный дискретный набор значений. В этих случаях гистограмма имеет вид разреженных "пиков" и кардинально отличается от непрерывного распределения Вигнера.
  * Однако с ростом размерности матриц ($k = 16, 32, 64$) комбинаторное многообразие возможных значений спектра стремительно увеличивается. Происходит эффект "расползания" дискретности, и гистограмма ансамбля Бернулли **асимптотически сходится** к плавному непрерывному распределению Вигнера. Это демонстрирует фундаментальный закон универсальности случайных матриц: локальная статистика уровней больших случайных матриц зависит от симметрии ансамбля, но не зависит от конкретного распределения отдельных элементов.
