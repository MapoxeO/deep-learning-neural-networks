## Описание 
Данная работа посвящена статистическому анализу расстояний между соседними собственными значениями случайных вещественных симметричных матриц. В теории случайных матриц этот феномен известен как **расталкивание уровней**. 

В ходе лабораторной работы моделируется поведение случайных матриц для двух типов распределений их элементов:
1. **Гауссов ортогональный ансамбль (GOE):** Элементы генерируются из нормального распределения $\mathcal{N}(\mu = 0, \sigma = 1)$.
2. **Ансамбль Бернулли:** Элементы принимают значения $\{-1, 1\}$ равновероятно.

### Алгоритм исследования

Для каждого ансамбля случайных матриц фиксированного размера $k \times k$ выполняется следующий численный эксперимент:

1. **Генерация ансамбля:** Создается выборка из $N = 10000$ случайных матриц. Случайными независимыми величинами заполняется верхний треугольник матриц (включая диагональ), после чего матрицы симметризуются: $A = A^T$.
2. **Вычисление собственных чисел:** Находятся действительные собственные значения матриц $\lambda_i$ с использованием метода `np.linalg.eigvalsh`.
3. **Нормировка расстояний:** Вычисляется разность между двумя соседними собственными числами $\Delta = \lambda_{2} - \lambda_{1}$. Для корректного сравнения матриц разных размеров и ансамблей с разной дисперсией производится нормировка полученных разностей на их среднее значение:
   $$s = \frac{\Delta}{\langle\Delta\rangle}$$
4. **Сравнение с теорией:** Строится гистограмма плотности распределения нормированных разностей $s$ и сопоставляется с теоретическим **распределением Вигнера** для ортогонального ансамбля:
   $$\rho_\Delta (s) = \frac{\pi s}{2} e^{-\frac{\pi s^2}{4}}$$

### Реализация и результаты

Скрипт проводит симуляции для матриц размерностей $k \in \{2, 4, 16, 32, 64\}$. Графики распределений плотности автоматически сохраняются в формате PDF в директорию `imgs/` с именами вида `{dist_type}-{N}-{k}.pdf`. 

Визуализация позволяет проследить, как с ростом размерности матрицы $k$ статистическое распределение разностей собственных чисел (даже дискретного ансамбля Бернулли) сходится к плавному теоретическому распределению Вигнера.
